# RUNS ITSELF: storyboard

**Concept:** an ad for recruitment automation. A recruiter's loop done by hand, once per applicant, turns into a hiring machine, and the ad never stops running either. The last frame is the opening frame: an empty DM box with a blinking caret. The loop seam sits inside the call to action.

The film's vocabulary is the client's own workflow language: **When → If → Then**, applied to a hire. Nothing cuts and nothing fades. Each scene is built from the previous scene's shapes, type and colour.

The sound tells the same story. Bar 1 (by hand) is drums and keystrokes only. The melody arrives at 2.0 s with the lime caret, because the machine brings it.

120 BPM · beat = 0.5 s · bar = 2 s · 7½ bars · something happens on every beat.
