# RUNS ITSELF: storyboard

**Concept:** one copy-paste done by hand turns into a machine, and the ad never stops running either. The last frame is the opening frame: an empty DM box with a blinking caret. The loop seam sits inside the call to action.

The film's vocabulary is the client's own workflow language: **When → If → Then**. Nothing cuts and nothing fades. Each scene is built from the previous scene's shapes, type and colour.

120 BPM · beat = 0.5 s · bar = 2 s · 7½ bars · something happens on every beat.
